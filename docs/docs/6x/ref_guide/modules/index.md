WarehousePG ships with a large set of modules and supports additional separately installed packages. They fall into four categories:

-   **[Bundled modules](bundled/index.md)** ship with WarehousePG and don't require a separate package install.
-   **[Extensions](extensions/index.md)** are open source packages that require a separate install on each host before you can enable them.
-   **[Procedural languages](procedural_languages/index.md)** extend WarehousePG with additional programming languages for writing functions and stored procedures.
-   **[External components](external_components/index.md)** are separately installed tools that integrate with WarehousePG but aren't database extensions.
