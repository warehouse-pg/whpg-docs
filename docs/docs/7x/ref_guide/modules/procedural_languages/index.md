---
title: Procedural Languages
description: Procedural language extensions for WarehousePG that require a separate package install on each host.

---

These procedural languages require installing a package on each host before use. PL/pgSQL, PL/Perl, and PL/Python ship with WarehousePG and don't require a separate install.

-   [PL/Container](pl_container.md) - Provides sandboxed execution environments using Docker containers for PL/Python and PL/R functions.
-   [PL/Java](../../../admin_guide/analytics/procedural_languages/pl_java.md) - Enables writing functions and triggers in Java.
-   [PL/R](../../../admin_guide/analytics/procedural_languages/pl_r.md) - Enables writing functions in the R statistical computing language.
