---
title: Installing Procedural Languages
description: Installation guides for procedural language extensions that require a separate package install.

---

PL/pgSQL, PL/Perl, and PL/Python ship with WarehousePG and don't require a separate install. The following procedural languages require installing a package on each host:

-   [PL/Java](../../../admin_guide/analytics/procedural_languages/pl_java.md) - Write functions and triggers in Java.
-   [PL/R](../../../admin_guide/analytics/procedural_languages/pl_r.md) - Write functions in the R statistical computing language.
