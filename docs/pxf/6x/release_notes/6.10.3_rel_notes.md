## PXF 6.10.3

Released: 8 Oct 2026

### Bug fixes

- Fixed an issue where queries on external tables that are partitions, or that have `CHECK` constraints, returned fewer rows than the table contained. The issue occurred when a query selected only columns that the partition or `CHECK` constraint doesn't reference. The external table protocol now always includes the columns referenced by constraints in the column projection sent to PXF.
- Fixed an issue where the `DemoTextResolver` example plugin rejected every `TEXT` or `CSV` write with the error `Unexpected record format, expected 1 field, found N`. The issue affected only the example plugin, not real connectors.
- Fixed a log4j class conflict. PXF now uses the log4j 1.x API.
