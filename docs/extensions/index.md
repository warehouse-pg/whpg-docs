title: Extensions
description: Bundled and additional extensions for WarehousePG.
---

WarehousePG ships with a set of bundled extensions that don't require a separate install, and supports additional extensions you install separately on each host before enabling them.

## Bundled extensions

Extensions that ship with WarehousePG. See the [bundled extensions](bundled/index.md) page for the full list, including a compatibility matrix.

## Additional extensions

Extensions you install separately on each host before enabling them. See [Additional extensions](additional/index.md).
