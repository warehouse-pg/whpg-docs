**Release date:** April 22, 2026

WarehousePG Backup and Restore 1.33.0 includes new features and a bug fix.

## Features

- **PGAA table support:** `gpbackup` and `gprestore` now back up and restore databases that mix Postgres Analytics Accelerator (PGAA) tables with regular heap tables, capturing only PGAA metadata rather than the underlying object storage data.
- Added support for `pg_extension_config_dump` in `gpbackup`.

## Bug fixes

- Fixed a nil pointer dereference in `DoCleanup` when backup directory creation fails.
