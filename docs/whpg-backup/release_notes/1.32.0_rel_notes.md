---
title: WarehousePG Backup and Restore 1.32.0 release notes

---

**Release date:** January 29, 2026

WarehousePG Backup and Restore 1.32.0 includes a change and an improvement.

## Changes

- **Extension-owned access methods:** `gpbackup` no longer includes extension-owned access methods in a backup.

## Improvements

- **Help text on empty invocation:** `gprestore` now prints help text when run without any options.
