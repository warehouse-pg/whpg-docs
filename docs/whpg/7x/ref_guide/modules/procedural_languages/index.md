---
title: Procedural Languages
description: Procedural language extensions for WarehousePG that require a separate package install on each host.

---

The following procedural languages ship with WarehousePG and don't require a separate package install — enable them with `CREATE EXTENSION` in the target database:

-   [PL/pgSQL](../../../admin_guide/analytics/procedural_languages/pl_sql.md)
-   [PL/Perl](../../../admin_guide/analytics/procedural_languages/pl_perl.md)
-   [PL/Python](../../../admin_guide/analytics/procedural_languages/pl_python.md)

No additional procedural languages are available yet.
